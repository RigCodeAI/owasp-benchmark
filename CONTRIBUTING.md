# Contributing

Contributions are welcome for scanner adapters, schema validation, reproducibility fixes, and factual corrections.

Changes that affect scoring or mappings must include tests and explain whether previous release scores would change. Do not commit credentials, private license files, organization identifiers, or proprietary scanner binaries.

Vendor disputes should open a public issue containing the exact run, finding, and proposed correction. Ground truth and scoring policy are never changed only to improve one product's result.
