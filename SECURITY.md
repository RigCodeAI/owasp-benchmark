# Security

BenchmarkPython is intentionally vulnerable. Run it only on loopback or inside an isolated private network. Do not expose it to the internet, reuse real credentials, or point the active-scanning scripts at any system you do not own and intend to test.

Report vulnerabilities in this harness through GitHub private vulnerability reporting. Findings deliberately present in OWASP BenchmarkPython are benchmark cases, not harness vulnerabilities.
